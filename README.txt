This folder contains contains Windcave PHP SDK (WindcavePayments folder) as well as the sample application showing how to use it.
The test application does not use any external components like databases, so can be ran by copying the content of this folder into subfolder of your web-server.
The entry point for the test application is app.php.

If you have any questions about the application or SDK, or would like to report a bug in either test application or SDK, please contact devsupport@windcave.com
